## Installation

> [!NOTE]
> This installation guide currently covers [Prism Launcher](https://prismlauncher.org/) and other launchers a like. If you are using a different launcher, you may need to adapt the steps accordingly.

### Prism Launcher

1. Open Prism Launcher and select **Add Instance**.
2. Select **Import** under Custom.
3. **Paste the following URL** into the Local file or link to a direct download field:

```
https://unnamed-modpack.lab.lutfilahdz.com/modpack.zip
```

4. Click OK to import the modpack.
